# YZM205 Web Tasarımı ve Programlama · 2026–2027 Güz

Muş Alparslan Üniversitesi · Mühendislik-Mimarlık Fakültesi · Yazılım Mühendisliği 2. sınıf

Sabah 70 dakikalık sunum, ardından soru · öğleden sonra proje atölyesi · derslik BLD-104 · Arş. Gör. Çağrı ŞAHİN

Bu ders uçtan uca web ürünü geliştirmeyi öğretir: araçlar, mimari, veri, API, bulut, önbellek, güvenlik, kalite, çapraz platform ve pazara çıkış. Ders notları bu depoda duruyor ve GitHub Pages ile yayımlanıyor. Her haftanın özet notu tarayıcıda açılan bir sayfadır ve sırası gelince açılır; diğer haftaların adresleri açıldıkça eklenir. Hoca dersi sunumdan anlatır, sen de evde aynı haftanın notundan tekrar edersin.
