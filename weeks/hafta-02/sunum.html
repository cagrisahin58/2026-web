Sınıfça

h1'i yanlışlıkla head'e yazdın. Ekranda ne görürsün?

<head>
  <meta charset="utf-8">
  <title>Satranç Kulübü</title>
  <h1>Bu haftaki etkinlikler</h1>
</head>
<body>
</body>

Tarayıcı head'in içinde ekrana ait bir öğe bulunca head'i orada kapatır ve h1'i body'ye taşır. Sayfa doğru görünür ama kod yanlış kalır, h1'i sen body'ye taşı.

Kendi index.html'ini tamamla

VS Code'da kisisel-sayfa klasörünü aç, index.html'de eksik olanı ekle ve kaydet.

  • En üstte <!doctype html>
  • <html lang="tr">
  • head'de <meta charset="utf-8">
  • head'de <title>Adın Soyadın</title>
  • header'daki nav'da iki bağlantı:
    <a href="index.html">Ana sayfa</a>
    <a href="projeler.html">Projelerim</a>

Live Server'da sekmede adın görünmeli, menüdeki iki bağlantı da sayfayı açmalı. Değişiklik görünmüyorsa önce kaydettin mi, ona bak: VS Code sekmesindeki nokta kaydedilmemiş değişiklik demek.

Sınıfça

Tek harf farkı: görsel nerede açılır?

kisisel-sayfa/
├─ index.html
├─ projeler.html
└─ img/
   └─ Afis.svg
<img src="img/afis.svg"
     alt="Kulüp afişi">

Windows dosya adında büyük ve küçük harfi ayırmaz, Live Server afişi bulur. GitHub Pages'in sunucusu ayırır, onun gözünde afis.svg diye bir dosya yoktur.
